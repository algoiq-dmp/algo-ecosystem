## Technical Terms

| Term | Definition |
|------|------------|
| **Signal** | A structured recommendation (entry, stop-loss, target) generated by a strategy |
| **Strategy** | An algorithmic rule set that analyzes market data to generate trading signals |
| **Hit Rate** | Percentage of signals that result in profitable trades |
| **Drawdown** | Peak-to-trough decline in strategy equity curve |
| **Sharpe Ratio** | Risk-adjusted return metric: (return - risk_free_rate) / volatility |
| **OHLC** | Open, High, Low, Close price data for a given timeframe |
| **Greeks** | Options risk metrics: Delta, Gamma, Theta, Vega, Rho |
| **IV (Implied Volatility)** | Market's forecast of likely price movement derived from option prices |
| **VaR (Value at Risk)** | Maximum expected loss over a given time period at a confidence level |
